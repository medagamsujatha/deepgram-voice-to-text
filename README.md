# 🎤 Voice Notes Maker (Deepgram API)

## 📌 Overview

Voice Notes Maker is a simple voice-to-text web application built using the Deepgram API. It allows users to record audio, convert speech into text, and view their Deepgram wallet balance in real-time.

This project was developed as part of a rapid prototyping coding challenge, focusing on functionality, API integration, and clean implementation.

---

## 🚀 Features

* 🎙️ Start/Stop audio recording
* 📝 Speech-to-text transcription using Deepgram
* 💰 Display Deepgram wallet balance
* ⚡ Minimal and fast user interface
* 📄 Plain text output (no database used)

---

## 🛠️ Tech Stack

* JavaScript (Node.js)
* HTML5 & CSS3
* Deepgram API

---

## ⚙️ Setup Instructions

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/deepgram-voice-notes-challenge.git
cd deepgram-voice-notes-challenge
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Add Environment Variables

Create a `.env` file in the root directory:

```
DEEPGRAM_API_KEY=your_api_key_here
```

### 4️⃣ Run the Application

```bash
npm start
```

---

## 📸 How to Use

1. Click **Start Recording**
2. Speak into your microphone
3. Click **Stop Recording**
4. View the transcription output
5. Check your wallet balance displayed on screen
